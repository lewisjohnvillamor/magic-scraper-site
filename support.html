Support

A real person reads this inbox · usually answered within a day or two

Email support@magicscraper.app and it reaches someone who can actually fix what you hit. No ticket number, no first-line script, no queue.

What to put in the email

The single most useful thing is the URL of the page you were scraping. Almost every problem is specific to one page's markup, and without the address there is nothing to look at. If the page is behind a login, say so and describe what the rows look like instead.

Then, briefly: what you expected, what happened, and whether the status line in the popup said anything. That is usually enough.

Things worth trying first

It found the wrong block Press Another table to cycle through the other candidates it ranked. If none of them is right, use Pick manually: click the rows, then shift-click anything else you want as a column.
Columns are called Text, Text 2… The page has no headers to name them from — common on card grids. Double-click a column header to rename it; the names are remembered for that site.
The crawl stopped early The popup says why. "No further Next link" means the site ran out of pages. A 429 means the site is rate-limiting you: set Speed to Gentle and try again.
Rows are still there after Clear Infinite scroll adds rows to the page itself, not to the extension. Use the Reload page button that appears after clearing.
Nothing is detected at all Try the sandbox. If it works there and not on your site, that is worth an email — send the URL.

Known issues in v1.21.7

Updated 1 October 2026 · all fixed, arriving in the next update

These were found in a review of the current version, and every one is already fixed. The fixes come as an automatic store update once review clears, so there is nothing to reinstall. Until then, here is what each looks like and how to get around it.

A crawl stops on page 2 when the Next button is only an arrow icon Pick Next by clicking the edge of the button rather than the arrow itself.
A crawl with no page limit keeps going round and round Happens when the last page's Next link leads back to page one. Set Max pages in step 2, Pacing, on the Crawl tab.
An address with a comma in it is split in two in step 4 Write the comma as %2C, e.g. ?brand=nike%2Cadidas.
A table with two columns of the same name loses the first one Headers like Name, Name. Use Pick manually and pick the cells as columns.
Renaming a column to a name another column already has overwrites it in the export Give it a name no other column uses.
Excel export turns IDs into numbers Leading zeros are dropped and IDs over 15 digits are rounded. Export JSON, or open the CSV with the column set to Text.
Compare with a file misses some number changes Long numbers outside a phone column (12345.67 vs 1234567), and barcodes over 15 digits that differ only at the end. Check those columns by eye.
A CSV from an old Mac app imports as one row Lines that end in a lone carriage return. Open and re-save it in any spreadsheet, then compare again.
Columns called constructor or toString show as switched off Rare. Rename the column and it behaves normally.
Schedules don't run until the browser is restarted Only right after you first allow schedules. Restart the browser once.
Stop on your own crawl can end a scheduled run that's going at the same time Avoid starting a crawl in the minutes a schedule is due.
Editing the list of pages while a scheduled run is going loses the edit The run writes back the list it started with. Edit the list after it finishes.
Resume after Stop during drill-down skips one row The row that was open when you pressed Stop. Drill it on its own afterwards.
A “verify you're human” check pauses drill-down but the crawl goes on Only in a crawl-and-drill run. Pass the check, then press Stop and Resume.
The popup keeps spinning after a start it couldn't make Usually because another run is going. Close and reopen the popup.
Columns come out as Column 1, Column 2 on Wikipedia-style tables The table keeps its header row inside the body. Double-click each header to name it.
A table with a two-row header puts the names over the wrong columns Headers like Home over Won and Lost. Rename the columns by double-clicking them.
Columns are named after page styling, like Backdrop Blur Sm Common on sites built with Tailwind. Double-click the header to rename it; the name is remembered for the site.
Image addresses start with /_next/image?url= Sites built with Next.js. The real image address is the part after url=, URL-decoded.
On Hacker News-style pages it picks the page layout instead of the list Press Another table until the stories appear.
Cards laid out three to a row come out three at a time No good workaround; the update reads the whole grid as one list.
Labels like Phone and Email come out as values Pages that list details as label and value. Click those columns' headers to leave them out.
Nothing is found on sites built from web components No workaround yet; the update reads inside them.

Hit something not on this list? Email it with the URL, and it goes on here until it is fixed.

Things no in-browser tool can reach

Closed shadow roots, cross-origin iframes, data that only a private API returns, PDFs in the browser's viewer, and anything behind a bot challenge. These are limits of the browser, not of this extension, and no amount of fixing on my end will change them. If your page is one of these, I would rather tell you that than take your money.

Licence keys

Your key arrives by email in your Gumroad receipt, the moment you buy. Paste it into the extension and click Activate — there is no account and no login. The same key works on every browser and computer you use, with no device limit and nothing to deactivate when you change machine.

If a key will not activate, send me the key and the exact wording of the message the popup showed. Cannot find the key? Search your inbox for the Gumroad receipt, or email from the address you bought with and I will dig it out.

Refunds

Seven days, no questions asked. Email with your licence key. Purchases are processed by Gumroad as merchant of record, so the refund itself is issued through them.

Need something scraped for you?

A site behind a login, one that fights back, or a scrape that has to run every morning without you — that is a project rather than a tool, and we take those on. Send the site, the fields you need, how often, and the budget and deadline you have in mind: support@magicscraper.app. There is more detail on the home page.

Price changes on a website, caught for you.

Checking a competitor’s prices, a supplier’s stock or a listing site’s new entries by hand is a job that gets skipped. Set the list up once, put it on a schedule, and Magic Scraper collects it again at the time you choose and shows you what moved: the old price struck through beside the new one.

Install for Chrome — free Install for Edge Scheduled runs and Changes are Pro, a one-time purchase.

Set it once, see what moved

01

Set up the list once

Open the product listing, category or search page and click the extension. Leave out the columns you don’t need; crawl every page if it runs on.

02

Save and schedule

In the gear menu, Saved setups: give it a name, then Schedule — once a day at a time you choose, every few hours, or every few minutes.

03

See what changed

Each run saves a file and keeps the result. The Changes tab shows the rows that changed, the ones that are new and the ones that are gone, with the old value struck through beside the new.

What the Changes tab shows

Crawl a list twice and the Changes tab compares the two: Changed, New and Gone, each a filter of its own. Rows are matched on a column you choose — a SKU, a product name, a link — so a price that moved is a change, not one row gone and another new. Export the changes gives you just those rows.

Have last month’s figures in a spreadsheet already? Compare with a file sets a CSV or Excel file against today’s list instead.

How scheduled runs work

At the time you set, the extension opens the saved page in a background tab, collects it with your saved choices — the columns you left out stay out, the names you gave stay — saves a CSV to your downloads, and closes the tab. Your own tabs are not touched.

It runs inside your browser, so it runs while the browser is running: a run that falls due while it is shut happens shortly after you next open it. Each run can also add its rows to your own Google Sheet, or post them to a webhook for Zapier, Make or your own code.

What people watch

A competitor’s prices on a category page. A supplier’s stock levels. New listings in a directory or on a marketplace search. A job board, a property list, an exhibitor list as it fills up. Anything that is a list on a page you can open.

It reads pages the way you do, in your own browser, with a pause between pages. It stops at a “verify you’re human” check rather than trying to get past it, and it is not built for watching thousands of pages a minute.

Reasonable questions

How can I track a competitor’s prices automatically?

Set up their listing page once in Magic Scraper, save the setup and put it on a schedule. Each run collects the page again, saves a file, and the Changes tab shows which prices changed since the last run.

Does it email me when a price changes?

No email. Each run saves a file and keeps the result for the Changes tab; it can also add rows to a Google Sheet or post them to a webhook, which can send an alert through Zapier, Make or your own code.

Does the computer have to be on?

Yes. Scheduled runs happen inside your browser, so they run while it is open; a run that falls due while it is shut happens shortly after you next open it.

How often can it check?

Once a day at a time you choose, every few hours, or every few minutes for something you need to watch closely.

Can I compare with a list I already have?

Yes. Compare with a file sets a CSV or Excel file against the current list and shows the changed, new and gone rows the same way.

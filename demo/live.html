About this practice page

A price board that moves while you watch

Most of the reason to scrape a competitor’s prices, a supplier’s stock or a list of open jobs is to see what changed since last time. That cannot be practised on a page that never changes, so this one changes every minute, on a fixed rule worked out from the clock: a couple of lines are repriced, one sells out, one leaves the board and the one that left last minute comes back. Everything else holds still, including each row’s Updated time, which is when that row last moved.

Why comparing is harder than collecting

Two snapshots are easy. Knowing which differences are real is not. Rows move position when one drops off, so comparing line 7 with line 7 reports changes that are not there. The fix is to match rows by something that identifies them — here the SKU — and then the differences are only the real ones: a few changed lines, one row gone and one row back.

Doing it in Magic Scraper

Open it on this page and export, or simply leave it. When the countdown passes zero, open it again: the Changes tab compares this run with your last run of the same list. Set Match rows on to SKU, and it lists what was added, removed and changed, which you can export on their own. Below the board, the page prints what moved this minute, so you can check the answer instead of trusting it. Run it on a schedule and the comparison happens without you.

In code

The board is drawn by a script, so the HTML holds an empty table; read it in a browser, or with a headless one. Once you have two snapshots, an outer merge on SKU does the comparison:

m = before.merge(after, on="SKU", how="outer", suffixes=("_before", "_after"), indicator=True)
added   = m[m["_merge"] == "right_only"]
removed = m[m["_merge"] == "left_only"]
changed = m[(m["_merge"] == "both") & (m["Price_before"] != m["Price_after"])]

A correct result

Each snapshot has 25 rows and 6 columns (SKU, Product, Maker, Price, Stock, Updated). Between two neighbouring minutes the comparison should find one row gone, one row new and three or four changed — usually two new prices and two stock changes, one line selling out and another coming back — with the other twenty-odd untouched. The line under the board gives the same counts for the minute you are looking at.

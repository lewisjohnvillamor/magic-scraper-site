Iframe table scraping

Live warehouse levels, refreshed every morning at 06:00.

Stock is held in two warehouses and the numbers below come straight from the warehouse system, which serves its own page. We embed it rather than copy it, so what you see is what the system says.

The table is in a same-origin iframe. It is a separate document with its own DOM: nothing in it is reachable from this page's document, and a scraper pointed at this URL alone will report that there is no table here. Same origin is the condition — a frame served from another domain is closed to every extension, by the browser, not by choice.

About this practice page

A table that lives in another page

Stock levels from a warehouse system, a booking calendar, a results table from a sports federation, a price list from a supplier’s portal: sites often show these by embedding another page in an <iframe> rather than copying the data in. To the eye it is one page. To anything reading the page it is two documents, and the table is in the one you did not ask for.

What a page-level tool sees

Ask for this address and you get the frame, not its contents. In Python, pd.read_html("https://magicscraper.app/demo/iframe") fails with “No tables found”; Excel’s From Web and Google Sheets’ IMPORTHTML come back the same. In the browser, document.querySelector('table') returns nothing, because the table belongs to the frame’s own document.

Getting the 24 rows

The frame here is served from the same site, which is the case that can be read. Magic Scraper steps into same-origin frames while it looks for data, so it finds the table directly. In the console, go through the frame:

document.querySelector('iframe').contentDocument.querySelectorAll('tbody tr').length   // 24

The more general route works for any frame: find its address in the src attribute (here iframe-stock.html) and open it on its own. Then it is an ordinary page with an ordinary table, and pd.read_html on it returns 24 rows by 6 columns.

When the frame is from another site

If the embedded page comes from a different domain, the browser keeps the two apart: no script on the outer page, and no extension working in it, can read inside. Opening the frame’s address in its own tab is then the only route, and usually an easy one. From version 2.1, Magic Scraper notices a large frame from another site and offers to open it in its own tab for you.

A correct result

24 rows: product, SKU, maker, the counts at Wigan and Rotterdam, and next dispatch. The Wigan column should add up to 2,830 and Rotterdam to 837 — a quick check that every row came through as a number.

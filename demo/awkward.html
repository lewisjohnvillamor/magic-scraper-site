About this practice page

A clearance list where the important number is outside the list

End-of-line pages, outlet sections and trade promotions often work like this one: a table of products at their old price, and a banner above it that changes everything — here, “−35% applies to every line below”. If you are comparing prices or deciding what to buy, the price you would pay is the one you want, and the page never writes it down.

What a scraper can and can’t know

Any good tool gets the table: ten lines with Product, SKU, Category, Was and Left, plus the product link. None of them can know that the banner applies to the rows. That is not a detection problem a better tool solves; it is a sentence written for people, and the connection between it and the rows exists only in the reader’s head. A scraper that silently invents a “Now” column would be worse than one that leaves it out.

Adding the missing column yourself

Collect the ten rows with Magic Scraper and export them, then add the discount as one formula. With Was in column D, put this in a spare column and fill down:

=VALUE(SUBSTITUTE(D2,"$",""))*(1-35%)

In pandas it is one line once the table is read:

import pandas as pd
df = pd.read_html("https://magicscraper.app/demo/awkward")[0]
df["Now"] = (df["Was"].str.lstrip("$").astype(float) * 0.65).round(2)

Write the rule down next to the data — “−35% from the banner, ends Sunday” — because in a week the sheet will be the only record of it. If you scrape the page on a schedule, a change to the banner will not show up as a change to any row, so check it by eye.

A correct result

10 rows. Walnut Tray was $429.00, so it is $278.85 after the discount; Jute Tray, Bone goes from $488.00 to $317.20. The Left column is a count, from 1 to 18, and arrives as numbers.

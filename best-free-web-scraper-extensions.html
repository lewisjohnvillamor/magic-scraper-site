How to choose

Try the export before you trust the scraper. Install it, open a page you actually need, and get a file out. If that step asks for money, an account or credits, you have found the real price.

Check what happens after the first page. Most real lists run over many pages, behind Next buttons, Load more or infinite scroll. Every tool here handles some of that; the practice site has each kind, so you can try them side by side.

Ask where the data goes. Some extensions keep everything in your browser; others read pages through their own servers or AI services. Their privacy policies say which.

Reasonable questions

What is the best free web scraper extension?

It depends on what “free” has to cover. If it must include exporting the data, Magic Scraper, Instant Data Scraper and Web Scraper (webscraper.io) all export CSV and Excel at no cost; Magic Scraper adds JSON, every page of a list, and the page behind each row on a free sample. If you want ready-made scrapers for named sites, Data Miner and No Code Web Scraper have them, with paid exports or page limits.

Which free web scrapers let you export to Excel?

Magic Scraper, Instant Data Scraper and Web Scraper (webscraper.io) export Excel and CSV free. Data Miner does within 500 pages a month. Ultimate Web Scraper and No Code Web Scraper put exports behind a paid plan, according to their own pricing pages.

Is Instant Data Scraper still maintained?

Its builder, Web Robots, says it no longer owns or supports it. It still installs and still works on many pages.

Do I need an account to use a web scraper extension?

Not for Magic Scraper, Instant Data Scraper or the free Web Scraper extension. Data Miner and Thunderbit need one, according to their sites.

Microsoft Edge

A web scraper for Edge: any table, every page, into Excel.

Magic Scraper is a free extension in the Microsoft Edge Add-ons store. Open a page with a table, a list or a grid of results, click the icon, and the rows are already found and named. One click follows Next through every page; another exports Excel, CSV or JSON. No account, no code, and nothing uploaded.

Scraping a table in Edge, start to finish

01

Install from Edge Add-ons

Press Get on the Magic Scraper listing, then pin the icon from Edge's puzzle-piece menu so it is one click away.

02

Click it on the page

The table or list is outlined on the page and shown with named columns. If it picked the wrong one, Wrong list? has the others, or point at the one you want.

03

Every page, then export

On the Crawl tab, Start crawling follows Next, Load more or infinite scroll to the end. Then Export CSV, or Excel and JSON from the arrow beside it.

Want something to try it on first? The practice site has a paginated catalogue, tables, infinite scroll and more, built to be scraped.

Tables that run over many pages

Most tables worth having don't fit on one page: search results, directories, product listings, order histories. Copying page by page is where an afternoon goes. The Crawl tab finds the page's Next button — in more than 80 languages — or its Load more button or infinite scroll, and keeps going, with a pause between pages so the site isn't hammered. Every page lands in the same table.

If the site stops you with a "verify you're human" check, the run stops and tells you rather than trying to get round it.

Lists that aren't tables

A lot of what looks like a table on screen is a grid of cards or a stack of boxes underneath. Edge's copy and paste turns those into one long column of text. Magic Scraper reads the repeating structure instead, so each card becomes a row and each field — name, price, rating, link, image — becomes a column, named from the page.

The rows link somewhere? Drill-down opens the page behind each row and adds what is there as columns: specs, contact details, or a table of price tiers with a row per tier.

Excel, CSV, JSON — or straight into Google Sheets

Excel files keep prices and counts as numbers, not text. CSV opens anywhere; JSON is there for code. Leave out the columns you don't want and rename the rest before you export, and it remembers those choices for that site next time.

Pro (a one-time purchase) adds saved setups, a list of pages run as one sheet, scheduled runs, changes since last time, and sending rows to your own Google Sheet or webhook.

Reasonable questions

Is there a free web scraper extension for Microsoft Edge?

Yes. Magic Scraper is in the Microsoft Edge Add-ons store and is free to install with no account: finding the table or list on a page, crawling every page of it, and exporting to Excel, CSV or JSON all cost nothing.

Can it scrape a table that goes over several pages?

Yes. When the list has a Next button, Load more or infinite scroll, the Crawl tab follows it page after page and adds every page to the same table. It finds Next buttons in more than 80 languages.

Does it work on tables that are not real HTML tables?

Yes. It reads the page's structure rather than its text, so grids of cards, lists and div-based tables come out as one row each with a column per field, the same as a real table.

Is the Edge version different from the Chrome version?

No. Edge runs Chrome extensions natively, and the Edge Add-ons listing is the same extension: the same detection, crawling, drill-down, side panel and exports.

Does my data get uploaded anywhere?

No. It runs inside Edge on the page you have open, and what it collects stays on your computer until you export it. There is no account and no server of ours in between.

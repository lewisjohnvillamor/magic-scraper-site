Lead generation

An association’s member directory, into a spreadsheet.

Trade associations and professional bodies publish who their members are: every installer, every manufacturer, every accredited firm in one industry. That is a ready-made, industry-specific lead list. Here is how to get it into Excel, including the directories split into A–Z pages and the ones with a profile page per member.

Install for Chrome — free Install for Edge Free: every member on every page, to Excel or CSV.

Four steps, start to finish

01

Open the directory

Most associations have a Find a member or Member directory page. Search with no filters to list everyone, or narrow it to your region or specialism.

02

Click the extension

Each member becomes a row: company, town, phone, website, membership grade or category — the columns named from the page. If it picked the wrong list, Wrong list? has the others.

03

Every page, every letter

Start crawling follows the pages of results. A directory split into A–Z pages: paste the letter pages into List of pages and they merge into one sheet. One long page split under letter headings comes out as one table with a Section column.

04

The profile behind each member

When the list shows only a name, drill-down opens each member’s profile and adds what is there — address, phone, email, website, services — as columns. Then export to Excel or CSV.

Why member directories make good lead lists

A member directory is one industry, already filtered: every firm on it paid to belong, so it is trading and it identifies with the sector. Many list a specialism, a region or an accreditation, which is the segmenting you would otherwise do by hand. And they are kept current by the association, which removes members who leave.

Put the directory on a schedule (Pro) and Changes shows new members as they join — the firms most likely to be buying.

Public lists and members-only lists

Most associations publish a public directory so customers can find accredited firms; that is the list to use. Some keep a fuller directory behind a member login. The extension reads what you can see in your own browser, signed in as you — but a members-only directory usually comes with terms that limit what you may do with it, so check them before using it for outreach.

Keeping it clean

Keep to company-level fields and leave out named individuals unless you have a clear reason; contacting the firms is covered by the marketing rules where you are. Reasonable questions

How do I export an association member directory to Excel?

Open the association’s member directory in Chrome or Edge, list all members, click Magic Scraper, crawl every page and export to Excel. Drill-down adds each member’s profile page if the list shows only names.

What if the directory is split into A–Z pages?

Paste the letter pages into List of pages and they run with the same setup and merge into one sheet. A single page split under letter headings comes out as one table with a Section column.

Can it read a members-only directory?

It reads what you can see in your own browser, so a directory you can open when signed in can be read. Members-only directories usually have terms that limit their use, so check them first.

Is it free?

Finding the members, crawling every page and exporting are free. Drill-down runs free on the first three rows; Pro, a one-time purchase, runs it on every row and adds schedules and Compare with a file.

Which associations does it work with?

Any whose member directory is a list on a web page. It isn’t built for particular sites; it reads the page’s structure, so the same steps work on most directories.

IMPORTXML and IMPORTHTML: what they can and can’t do

IMPORTHTML(url, "table", n) pulls the nth real HTML table or list from a public page, and IMPORTXML(url, xpath) pulls whatever an XPath expression matches. For a simple public table that you want to refresh inside the sheet, they are the right tool, and free.

They fetch the page from Google’s servers and read only what the server sends before any JavaScript runs. So they come back empty or with the wrong thing when the list is drawn by a script, when it is a grid of cards rather than a table, when it is behind a login, when it runs over several pages, or when the site refuses Google’s servers — which many do. That is when Imported content is empty or Could not fetch url appears.

Why an extension gets what the formulas can’t

The extension reads the page you have open, in your own browser, after it has finished loading: the same rows you see, signed in as you. It doesn’t need a table or an XPath — it finds the repeating rows and names a column per field — and it follows Next, Load more and infinite scroll to collect every page.

Reasonable questions

Why is IMPORTXML returning empty or Could not fetch url?

IMPORTXML fetches the page from Google’s servers and reads only what the server sends before JavaScript runs. Lists drawn by scripts, pages behind a login and sites that refuse Google’s servers come back empty. An extension that reads the page in your own browser gets them.

Can I scrape a website into Google Sheets for free?

Yes. Open in Google Sheets is free: it copies the table the extension found and opens a new sheet to paste into, with every column intact.

Can it scrape multiple pages into Google Sheets?

Yes. Start crawling on the Crawl tab follows the list through every page first, then the whole table goes to Sheets at once.

Can Google Sheets update automatically from a website?

IMPORTHTML and IMPORTXML refresh by themselves for simple public tables. For anything else, Magic Scraper Pro can run a saved setup on a schedule and add each run’s rows to the same sheet, while your browser is running.

Does it get access to my Google Drive?

No. Send to Google Sheets uses Google’s narrowest permission: the extension can open only the spreadsheets it created itself.

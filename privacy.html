Magic Scraper — Privacy Policy

Last updated 20 September 2026 · applies to the Magic Scraper browser extension for Chrome and Edge

Magic Scraper keeps your data on your machine. It has no servers of its own, no analytics and no telemetry. Everything it reads stays in your browser, and everything it produces goes only where you save it. Detecting a table, picking one by hand and exporting it make no network requests at all. The only requests the free extension ever makes are for further pages of the site you are already on, and only once you press Start crawling — never to a server of ours, because there isn't one. There is exactly one exception, described below, and it happens only if you buy Pro: your licence key is sent to Gumroad, once, to confirm the purchase.

What it reads

When you open the popup on a page, the extension reads that page's visible content — the text, links and image URLs already rendered in your browser — in order to find the repeating rows and turn them into a table. If you turn on drill-down, it also opens the pages your rows link to and reads them the same way.

It does not read pages you have not opened the popup on, does not run in the background, and does not touch form fields, passwords or cookies.

What it stores, and where

Everything is kept in your own browser. Nothing is uploaded. It lives in three places, and it is worth knowing which, because they are not all cleared the same way.

WhatWhy
Rows from a drill-down run So results survive the popup closing while the run continues. IndexedDB on the extension's own origin. Removing the extension deletes it.
Your setup for a site — speed, excluded columns, renames, removed rows, the link column So you do not reconfigure the same site every visit. Kept per site, for the 20 most recent.
A pending drill-down preview So a half-configured chain survives the popup closing.
A crawl's rows, written as it goes So a long run survives the tab closing, a crash, or the power going out. Held in IndexedDB on the scraped site's own origin rather than in the extension, because that is the only storage without a 10 MB ceiling. Removing the extension does not delete this — clear that site's data in your browser, or press Clear in the popup.
Up to five past runs of the same list So a new run can be compared with the last one and tell you what changed. Same per-site IndexedDB, and the same caveat about deletion.
Saved setups, and any schedule attached to one So the next site like this one takes seconds. Settings only — a setup never holds scraped rows. You can export them to a file, and that file is yours.
An interrupted run A crawl writes its rows to your browser's own storage, on the site's origin, as it goes — so a tab that dies does not take them with it. Offered back the next time you open the popup there, and thrown away as soon as a run finishes cleanly or you discard it. Nothing is downloaded for this.
A scheduled run's CSV Only if you set a schedule. Each run writes its result into your downloads folder, because nobody is there to press export. An ordinary file: it stays after the extension is removed.

What leaves your machine

Your data: nothing. The only network requests the extension makes while scraping are to the site you are already on: when a site paginates by URL, it fetches the next page of that same site directly, exactly as your browser would if you clicked the link. Your rows, your columns, the pages you visit and the files you export never leave your machine.

One exception, and only if you buy Pro: activating your licence. When you paste a licence key and press Activate, the extension sends that key and the product ID to api.gumroad.com, once, so Gumroad can confirm the purchase. That is the whole request. It carries nothing about the page you are on, the data you have collected, or anything else about you. The answer is saved locally and never checked again — there is no call on startup, no periodic re-check and no telemetry. A free installation never makes this request at all, and never asks for permission to.

We do not store your name or email address, even though Gumroad's reply contains them.

Files you export (CSV, XLSX, JSON) are written to your own downloads folder. Where they go after that is up to you.

Permissions, and why each one exists

PermissionWhy
activeTab Read the page you are looking at, only when you open the popup on it.
scripting Run the detection and extraction code inside that page.
downloads Save your CSV / XLSX / JSON file — and, if you set a schedule, the CSV each run produces while you are not there.
tabs, storage, all-sites access (optional) Requested only if you switch on drill-down, which has to open each row's page in a background tab and keep the results while it works. Decline it and the rest of the extension still works.
alarms (optional) Requested only if you put one of your own saved setups on a schedule. It is a timer and nothing else: it wakes the extension when a run is due. Scheduled runs happen only while your browser is open — an extension cannot wake a browser that is shut, and there is no server of ours to do it instead.
api.gumroad.com (optional) Requested only when you activate a Pro licence, for the single check described above. Free users are never asked for it.

Scheduled runs

If you schedule a saved setup, the extension opens that page in a background tab at the time you chose, collects it, writes a CSV to your downloads folder and closes the tab again — without you watching. Two things follow from that, and you should know both before you switch it on.

  • It visits that site in your browser, as you, on a timer. If you are signed in to the site, the run is signed in too, exactly as it would be if you opened the page yourself.
  • It writes files to your downloads folder while you are doing something else.

Nothing about those runs is sent anywhere. The rows, the files and the schedule itself stay on your machine, and a schedule stops the moment you switch it off or remove the extension.

Children

Magic Scraper is a developer and analyst tool. It is not directed at children and collects no personal information from anyone.

Your responsibility when scraping

The extension automates reading pages you can already see. You remain responsible for respecting the terms of service, robots.txt, rate limits and copyright of the sites you use it on, and for handling any personal data you collect lawfully.

About this website

Everything above is about the extension, which has no server and never did. This website is a different thing and now has one small piece of one, so it is worth saying plainly rather than leaving you to find it.

The “What’s being built” list on the home page has an I’d use this button. Pressing it stores a number — how many people pressed it — and a random id your browser makes up for itself, so that pressing twice does not count twice. That id identifies nobody, is not a cookie, is not joined to anything, and is not shared. No IP address is logged and there is no analytics on this site.

If you then choose to leave an email address, that address is kept, with the item you left it on, for one purpose: telling you when that thing ships. It is optional, the vote is already counted without it, and asking to be removed at support@magicscraper.app is enough.

None of this touches the extension. It has no idea the website exists.

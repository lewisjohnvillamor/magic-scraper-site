Site guide

Scrape Amazon search results into a spreadsheet.

Search Amazon, click the icon, and every result arrives with its price, rating, review count, ASIN and a clean product link in columns of their own, sponsored results marked. It works on every Amazon country site and follows Amazon’s own pager.

Install for Chrome — free Install for Edge Free exports, no paywall on your data. Amazon has been read by name since version 1.22; see every site read by name.

Going further, and the limits

This reads Amazon search results, the list a search shows. It is not a product-page or review scraper. Drill-down can open each product’s page from the Link column and add what it finds there; try it on the three free rows to see what comes back before relying on it. If Amazon shows a robot check, the run stops and hands you the tab.

Whether you may collect from a site is between you and that site: its terms, its robots.txt and data-protection law. Magic Scraper reads only what your browser already shows you, paces itself gently by default, and a “verify you’re human” check stops the run and hands you the tab; it never tries to get past one.

Reasonable questions

Is there a free Amazon scraper?

For search results, yes. Magic Scraper reads each result’s title, price, rating, review count, ASIN and link, follows every page and exports CSV, Excel or JSON for free.

Does it work on amazon.co.uk, amazon.de and the others?

Yes. It recognises the results by how they are built, which is the same in every country.

Does it scrape Amazon reviews or product pages?

Not by name. It reads search results. Drill-down can open each product’s page and add the fields it finds; check the three free rows before relying on it.

What if Amazon asks me to prove I am human?

The run stops and hands you the tab. Magic Scraper never tries to get past a check like that.

Do I need an account or an API key?

No. It reads the page you are looking at, in your own browser. Nothing is sent to us; there is no server of ours to send it to.

What happens if Amazon changes its design?

Magic Scraper falls back to reading the page the ordinary way, which usually still finds the list. Tell us and the site reading is updated in the next release.

Changelog

What changed, update by update.

Updates arrive by themselves through the Chrome Web Store and Edge Add-ons, once each one clears store review. This page lists what each one changed, in plain words, including anything that was removed or moved to Pro, so an update never surprises you.

Install for Chrome — free Install for Edge In the stores now: v1.22.2.

v1.22.3

Next update. Built 17 October 2026, tested, not in the stores yet.

  • Business directories get named columns: Name, Phone, City, State, Postcode, Website and Map Link, instead of generic labels, on chamber of commerce and Yellow Pages-style directories.
  • Drill-down reads a member's profile page: address, phone, fax, email, website and social pages, leaving out the directory's own header, footer and links.
  • Research paper pages (arXiv, PubMed, journals): drill-down reads the title, authors, date, journal, DOI, PDF and abstract.
  • Links on pages that set a different base address now point to the right pages.
  • A table that a page fills in later is no longer offered as rows with nothing in them.
  • Larger buttons and clearer text in the popup.

v1.22.2

In the Chrome and Edge stores now. 15 October 2026.

  • A pick made by hand from the side panel shows its columns there straight away.
  • Includes 1.22.1, which never went out on its own: when the rows on screen each link to a page of their own, the Data tab says so, and Show me takes you to drill-down.
  • A first install opens a page showing where the icon went (new extensions hide in the puzzle-piece menu). Removing the extension opens one optional question on our website.

v1.22.0

1 October 2026.

  • Keep it open beside the page in the browser's side panel: it stays while you click and follows the tab you're on.
  • Reddit, Amazon search, Hacker News, PubMed and arXiv read into named columns. What each gives.
  • Wikipedia-style tables get their real headers, two-row headers included. Cards laid out three to a row come back as one list. Lists built from web components are found.
  • Image columns hold the whole address of the original image, not a resized copy. Columns are no longer named after styling classes.
  • Fixes from two read-throughs of the code (1.21.8 and 1.21.9): a Next button drawn as an icon no longer ends the crawl at page 2, a Next link that loops back no longer crawls forever, columns with the same header keep all their cells, and comparing with a file catches numbers that differ only in the last digit.

v1.21

22 to 25 September 2026.

  • One setup over a list of pages: paste the addresses, and the page you're on is crawled first, then each address in a tab of its own with the same setup, drill-down included. All of it comes back as one sheet with a List column.
  • Changed: a list of pages is free for the first two addresses; Pro runs them all.
  • A queued run's rows survive the popup closing. Drilled rows whose page showed nothing are kept instead of thrown away. An empty pick no longer fails the run.

v1.20.14 to 1.20.20

20 to 22 September 2026.

  • Recovering a run whose tab closed is free, no longer Pro.
  • Removed: the CSV auto-save during long runs. It could stop on a file chooser every few thousand rows; recovery keeps those rows without interrupting you.
  • A “verify you're human” check stops the run and hands you the tab, instead of retrying into it.
  • Stop responds at once, instead of finishing the pause it was pressed during. A schedule that had lapsed no longer shows as active.
  • Detection: menus of links, page layouts and font-size classes no longer win over the real list, or name its columns.

Earlier

1.17 compared a run with the last one of the same list. 1.16.1 added named setups you can reuse and export. 1.16.0 brought back runs whose tab closed. Each of those has grown since; the entries above say how.

How updates work

Each update is checked by Chrome and Microsoft before it reaches you, then installs by itself. A Pro licence keeps working across every update: there is no paid upgrade.

When an update removes something, or moves it between Free and Pro, it is listed here under that version, in words, as the entries above show. If something you relied on changed and isn't listed, tell us.

Reasonable questions

Which version of Magic Scraper is in the stores?

Version 1.22.2, on both the Chrome Web Store and Edge Add-ons. Version 1.22.3 is built and tested and goes to the stores next.

How do Magic Scraper updates arrive?

Automatically, through the Chrome Web Store or Edge Add-ons, once each update has cleared store review. You don't need to reinstall.

Do I have to pay for updates?

No. A Pro licence is paid once and keeps working across every update.

Will an update remove a feature I use?

Anything removed, or moved between Free and Pro, is listed on this page under the version that changed it.

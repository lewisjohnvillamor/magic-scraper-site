How a scrape actually goes

Five steps, in the order you'd hit them. Most pages stop at the first one.

01

It finds the data

Tables, card grids, repeated lists, schema.org markup, open shadow roots and same-origin iframes. Columns get named from the markup rather than called col_1. Wrong block? Cycle to the next candidate.

02

Or you point at it

When a layout is too odd to guess — a table plus a price floating outside it — click the rows, then shift-click the extra elements. Several regions of a page become one table.

03

It walks the pagination

Finds the Next control, follows URL or click pagination, handles infinite scroll, and when a site answers with a 429 it waits and retries instead of hammering. If a site asks you to prove you're human, the run stops and hands you the tab — it never tries to get past the check. You can stop mid-run and keep what it has — here it is on a business directory.

04

It opens the page behind each row

Confirm what to take from one detail page and it repeats that for every row, merging the fields back in as extra columns. Chain several levels deep if the data is buried — how drill-down works.

05

Then does it for a whole list of pages

Paste the addresses — every category, every town. The page you're on is crawled first, then each address in a background tab with the same setup, drill-down included. The rows come back as one sheet, with a List column saying where each came from.

Where your data goes

Nowhere. Most tools in this category route your scrape through their servers. This one has no servers.

Detection, crawling and export all happen inside your browser. There is no server of ours for your data to pass through, because there is no server of ours.

Detecting a table, picking one by hand and exporting it make no network requests at all — not analytics, not a version check, not a ping. The only requests the free version ever makes are for further pages of the site you are already on, and only once you press Start crawling: the same pages your browser would fetch if you clicked through them yourself.

What it keeps — a run in progress, past runs to compare against — is stored inside the extension, where the website you scraped cannot read it. A file you compare against is read on your computer and never uploaded.

If you buy Pro, activating your licence sends the key to Gumroad once to confirm the purchase. Nothing about the page you're on goes with it, and nothing is sent afterwards.

Reasonable questions

Do I actually need Pro?

Only if you want the page behind every row. Crawling pagination is free, however many pages — that part isn't metered at all, and if the tab dies partway through a long run the rows are offered back the next time you open the popup, which is also free. Drill-down is the paid feature, and free runs it on the first three rows so you can see exactly what comes back from your own site before deciding. Pro adds saved setups you can name and reuse, running one on a schedule, running one setup over a whole list of pages (free does the first two), and comparing a run with the last one of the same list — or with a file of your own.

Can it tell me which leads I don't have yet?

Yes, with Pro. Scrape the directory, open the Changes tab, and choose Compare with a file — your CRM export, as CSV, Excel or JSON. Every row on the page that isn't in your file is marked new, and Export the changes saves just those. Rows are matched on a column both have, usually the phone number or website, and a phone matches however it's written. The file is read on your computer and never uploaded.

Can it run on a schedule while I'm not there?

While Chrome is open, yes — point a saved setup at a time of day or an interval and it opens the page in a background tab, collects it, saves a CSV and closes the tab again. While Chrome is closed, no. An extension has no way to wake a browser that isn't running, and anyone who tells you otherwise is running a server somewhere. A run that came due overnight happens shortly after you next open Chrome rather than being skipped. If you genuinely need collection on a machine that's asleep, that needs a server, and this deliberately doesn't have one — the done-for-you service is the honest answer there.

Will it work on the site I have in mind?

Probably. It reads what your browser has already rendered, so what you can see, it can usually take. It can't reach closed shadow roots, cross-origin iframes, data only a private API returns, or anything behind a bot challenge — those are limits of the browser itself, not of this extension. When a site does ask you to prove you're human, the run stops and hands you the tab rather than trying to get past it. Try the free version on that exact site before paying.

Am I allowed to scrape a site?

That's between you and the site, and this tool doesn't change the answer. Check its terms, respect robots.txt where it applies, think about data-protection law if the rows are about people, and don't hammer anyone — the speed setting is there for exactly that, and the default is deliberately gentle.

What if I change computer?

Paste the same key. One licence covers every browser and machine you use. There's no device count, nothing to deactivate, and no login to lose.
